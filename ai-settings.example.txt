# Налаштування ШІ для «Поради бабусі» — ШАБЛОН.
# Під час першого запуску сервер сам скопіює його у файл ai-settings.txt.
# Ключі вписуй уже в ai-settings.txt: він не потрапляє в git.
# Після змін закрий чорне вікно й знову запусти «Запустити з ШІ.bat».
#
# ── ВАРІАНТ 1. Ollama: безкоштовно на твоєму комп'ютері ────────────────
#   Нічого вписувати не треба: якщо Ollama запущена й має хоч одну модель,
#   сервер знайде її сам. Українською найкраще з легких моделей пише gemma3.
#   Завантажити модель (один раз, у терміналі):   ollama pull gemma3:4b
#   Потужніший комп'ютер (16 ГБ пам'яті й більше):  ollama pull gemma3:12b
#   Якщо моделей кілька й хочеш конкретну, прибери # і впиши назву:
# OLLAMA_MODEL=gemma3:4b
#
#   Зауваж: команда «ollama launch claude» запускає Claude Code (агента для
#   програмування в терміналі), а не модель Claude. Для сайту вона не потрібна.
#
# ── РОЗУМНИЙ ПОШУК В ІНТЕРНЕТІ (подарунки, послуги, враження) ─────────
#   Безкоштовно: створи акаунт на https://ollama.com, відкрий
#   https://ollama.com/settings/keys → створи ключ і встав його нижче
#   замість «встав-сюди-ключ». Ключ секретний.
#   Якщо вписано ключ Claude API (варіант 2), пошук іде через Claude і цей ключ не потрібен.
#   Без жодного ключа сайт підбирає, що шукати, і відкриває пошук у магазинах.
OLLAMA_API_KEY=встав-сюди-ключ
#
# ── ВАРІАНТ 2. Claude API: найкраща якість українською ─────────────────
#   Якщо впишеш ключ, сайт використовуватиме Claude замість Ollama, а пошук
#   в інтернеті піде через вебпошук Claude (окрема плата: близько 10 $ за 1000 пошуків).
#   Ключ секретний: не викладай цей файл в інтернет і нікому не надсилай.
#   1) Увійди на https://platform.claude.com і поповни баланс
#      (API оплачується окремо від підписки Claude, за кількість запитів).
#   2) Відкрий https://platform.claude.com/settings/keys → Create key.
#   3) Встав ключ (починається з sk-ant-) замість «встав-сюди-ключ».
ANTHROPIC_API_KEY=встав-сюди-ключ

# ANTHROPIC_MODEL_QUICK=claude-haiku-4-5-20251001
