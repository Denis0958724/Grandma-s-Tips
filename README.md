# Поради бабусі

Сайт, де люди отримують теплі життєві поради від бабусь: про стосунки, сім’ю, доброту й підтримку. Бабусі мають профілі, записують короткі аудіо- та відео-поради, відповідають на питання й проводять платні консультації (80 % оплати отримує бабуся).

## Швидкий старт

1. Завантаж проєкт: зелена кнопка **Code → Download ZIP** на GitHub (або `git clone https://github.com/Denis0958724/Grandma-s-Tips`) і розпакуй.
2. Без ШІ: просто відкрий `Поради бабусі.html` у браузері.
3. З ШІ на Windows: встанови Python 3 і двічі клацни `Запустити з ШІ.bat`. Під час першого запуску сервер сам створить `ai-settings.txt` із шаблону `ai-settings.example.txt`; ключі вписуй туди (подробиці нижче).

Повний опис проєкту й журнал змін — у файлі [`ОПИС_ПРОЄКТУ.md`](ОПИС_ПРОЄКТУ.md).

## Модель: навчання з учителем

* **Задача:** за віком користувача оцінити ймовірність життєвого етапу (ще не в шлюбі / у шлюбі / розлучення / вдівство) і за нею порадити тему та бабусю.
* **Алгоритм:** багатокласова логістична регресія (регресійний класифікатор), ознаки — вік, вік², вік³.
* **Дані:** UCI Adult (Census Income), перепис США 1994 р., ліцензія CC BY 4.0. Автори: B. Becker, R. Kohavi. https://archive.ics.uci.edu/dataset/2/adult
* **Якість на тестових даних:** точність 62 % проти 46 % у базової моделі (завжди «у шлюбі»), 5-кратна перехресна перевірка — 62,5 %.
* **Стать свідомо не використовується:** у наборі заміжніми записано лише 15 % жінок проти 61 % чоловіків, і модель перейняла б цей перекіс (розділ 6 ноутбука).

На сайті модель рахується прямо в браузері, ті самі ймовірності, що й у ноутбуці. Вік вводиться в опитуванні при першому запуску (або в розділі «Бабусі»).

## ШІ на своєму комп’ютері

Підбір ідей, розмова з бабусею й демо-відповіді бабусь потребують мовної моделі. У Claude вона вбудована, а на комп’ютері її дає `server.py`.

1. Встанови Python 3 з https://www.python.org/downloads/ (під час встановлення постав галочку «Add python.exe to PATH»).
2. Обери, звідки брати ШІ:
   * **Ollama** (безкоштовно, без інтернету): встанови https://ollama.com і один раз виконай у терміналі `ollama pull gemma3:4b` (3,3 ГБ; на потужному комп’ютері краще `gemma3:12b`). Більше нічого налаштовувати не треба: сервер сам знайде Ollama й модель.
   * **Claude API** (найкраща якість українською): створи ключ на https://platform.claude.com/settings/keys і встав його в `ai-settings.txt` у рядок `ANTHROPIC_API_KEY=`. API оплачується окремо від підписки Claude, за використання. Якщо ключ вписано, він має пріоритет над Ollama.
3. Двічі клацни `Запустити з ШІ.bat`. Відкриється браузер із сайтом за адресою http://127.0.0.1:8000. Поки чорне вікно відкрите, ШІ працює. У ньому видно, яку модель знайдено.

**Розумний пошук в інтернеті** (вкладка «Ідеї → Знайти»): шукає справжні товари, послуги й враження під профіль коханої людини.
* Безкоштовно: ключ з https://ollama.com/settings/keys (потрібен безкоштовний акаунт) у рядок `OLLAMA_API_KEY=` файлу `ai-settings.txt`.
* Або через Claude API, якщо вписано його ключ (вебпошук Claude оплачується окремо).
* Без ключів сайт підбирає, що шукати, і відкриває пошук у Rozetka, Prom, OLX і Google.
Посилання в результатах беруться лише з того, що реально знайшов пошук.

Команда `ollama launch claude` для сайту не потрібна: вона запускає Claude Code (агента для програмування в терміналі) на відкритій моделі, а не модель Claude.

Ключ залишається на твоєму комп’ютері: сайт звертається лише до `server.py`, а той — до моделі. Сервер приймає запити тільки з цього комп’ютера. Якщо просто відкрити HTML-файл подвійним кліком, сайт працює без ШІ, з ідеями за правилами.

## Що в прототипі імітовано

* Профілі бабусь вигадані.
* Оплата й донати не списують гроші.
* Аудіо- й відео-поради бабусь озвучуються синтезом мовлення браузера з субтитрами. Власні записи (мікрофон, камера або файл) живуть до перезавантаження сторінки.
* Дані користувача зберігаються лише в його браузері.
* Відповіді від ШІ й розмова з бабусею працюють у Claude або через `Запустити з ШІ.bat`.
